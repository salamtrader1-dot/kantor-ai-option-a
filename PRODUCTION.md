## 🎮 How to Use

### View Live Demo
```
https://kantor-ai-option-a.vercel.app
```

### Local Development
```bash
git clone https://github.com/salamtrader1-dot/kantor-ai-option-a.git
cd kantor-ai-option-a
npm install
npm run dev
# Open http://localhost:3000
```

### Interactions
- **Click any staff card** → Staff celebrates (sound + animation)
- **Hover staff cards** → Tooltip + sub-metrics reveal
- **Toggle theme** → Dark/light mode switch
- **Watch office** → Random activities every 10s with chat bubbles
- **Click leaderboard** → Office highlights corresponding staff
